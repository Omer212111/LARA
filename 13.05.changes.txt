SUPERVISOR (supervisor.py)
--------------------------
Deterministic rules first, LLM only for ambiguous states:
  no plan              → Explorer
  has plan, 0 runs     → Executor
  3 exec failures      → Explorer (re-plan)
  MAX_ITERATIONS hit   → FINISH
  task_done=True       → FINISH
  else                 → LLM decides (Explorer / Executor / FINISH)


EXPLORER (explorer.py — GPT-4.1-nano)
--------------------------------------
1. Detect relevant apps by keyword from task text
2. Pre-inject API docs for detected apps into system prompt
3. OpenAI function-calling loop (up to 10 rounds):
     Round 0: tool_choice="required"  → must call explore_app_apis or get_api_details
     Round 1+: tool_choice="auto"     → continues until no tool calls
4. Output: structured plan with step-by-step pseudocode


EXECUTOR (executor.py + app_agents/)
-------------------------------------
AppOrchestrator  (app_agents/base.py)
     │
     ├── detects active app from plan step
     ├── selects matching Specialist prompt
     │
     ├── SpotifyExecutor   ← code templates for rating/finding songs
     ├── GmailExecutor
     ├── AmazonExecutor
     ├── FileSystemExecutor
     └── fallback: generic REACT_EXECUTOR_SYSTEM

  ReAct loop (up to 5 steps per run):
     Think → Write code → Execute in AppWorld sandbox → Observe output → Repeat

  On complete_task(): sets task_signal_complete, extracts final_answer


REVIEWER (reviewer.py — GPT-4.1-nano)
---------------------------------------
Only fires when: complete_task() called BUT answer was WRONG
  Receives: task, plan, last code, all execution outputs, failed test requirements
  Diagnoses: ENVIRONMENT_ERROR | WRONG SCOPE | WRONG METRIC | WRONG FIELD | ...
  Output: structured FIX_INSTRUCTION appended to state for next Executor run
